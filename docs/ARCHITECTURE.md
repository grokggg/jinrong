# Vκ-RAF∞ 架构设计文档

## 1. 设计哲学

### 1.1 范式差异

| 维度 | 传统量化模型 | Vκ-RAF∞ |
|------|------------|----------|
| 核心目标 | 预测个股收益率，做横截面排序 | 诊断系统稳态与脆弱性，输出风险约束 |
| 风险视角 | 事后风控（波动率、止损、最大回撤） | 前瞻性（系统脆弱性、相变预警、尾部EVT） |
| 参数迭代 | 回测调参后固化，人工复盘 | 自动化信号验证闭环，滚动校准+熔断 |
| 代码架构 | 业务逻辑、参数、风控高度耦合 | 非侵入插件架构，核心层与扩展层严格隔离 |
| 因子检验 | IC、IR、分组回测（相关性） | PSM+格兰杰+事件研究（因果性） |

### 1.2 五层架构

1. **核心层（永久冻结）**：Mκ V2 + 三大校正 + 赛道Mk + 双层哨兵
2. **验证闭环层**：信号记录 → 到期验证 → 年度校准 → 熔断保护
3. **P0 审计层**：数据质控 / 校准风控 / 因果审计（审计增强，不改变计算）
4. **P1 增强层**：HMM / PID / 生命周期 / EVT（扩展增强，可开关）
5. **v4.3 跨学科层**：W_E / W_I / W_N / MFI（理论扩展，逐步验证）

### 1.3 非侵入式铁律

- 所有扩展模块**只读**核心系统输出，**不回写**核心参数
- 所有扩展模块**默认关闭**，关闭即完全等价于纯核心版
- 所有扩展模块可**独立开关**，互不依赖
- 核心 Mκ 公式、已固化参数、基础架构**永久冻结**

## 2. 核心层详解

### 2.1 Mκ V2 全局稳态指数

四因子高斯隶属度加权：

```
Mκ = 0.45 + 0.12·f(估值疏密度) + 0.10·f(波动率) + 0.08·f(趋势) + 0.05·f(量比)
```

输出范围 [0.35, 0.80]，五档分层：

| Mκ区间 | 分层 | 基准仓位 |
|--------|------|---------|
| <0.45 | 崩溃区 | 0% |
| 0.45-0.55 | 高危区 | 20% |
| 0.55-0.58 | 预警稳态 | 50% |
| 0.58-0.72 | 黄金稳态 | 80% |
| ≥0.72 | 过热区 | 30% |

### 2.2 三大校正因子（乘法叠加）

- **C_corr 关联发散**：市场平均相关性升高 → 分散化失效 → 降仓
- **W_L 流动性**：成交额萎缩 → 流动性收紧 → 降仓
- **W_S 多尺度结构**：高频能量占比升高 → 结构风险 → 降仓

### 2.3 赛道级 Mk

双序参量：
- **ρ 博弈曲率**：成交额集中度 + 价格离散度
- **Ξ 叙事分歧**：波动率 + 涨跌幅分化

三档信号灯：
- 🟢 绿灯（ρ<0.65 且 Ξ<0.5）：可正常开仓
- 🟡 黄灯（ρ>0.65 或 Ξ>0.5）：禁止新仓
- 🔴 红灯（ρ>0.75 或 Ξ>0.65）：强制减仓

## 3. 验证闭环

### 3.1 完整流程

```
每日实盘数据 → v4.6哨兵 → 自动记录当日所有信号
                           ↓
                    独立验证数据库存储
                           ↓
              到期自动验证（30/60天）
                           ↓
              准确率/偏差统计 + 渐进式参数校准
                           ↓
              反向修正参数（年漂移≤10%，单次≤5%）
```

### 3.2 校准铁律

- 样本 < 100：不校准
- 100 ≤ 样本 < 300：微调阈值，单次漂移 ≤ 5%
- 样本 ≥ 300：渐进式校准，年漂移 ≤ 10%
- 连续2季度准确率 < 60%：观察预警
- 连续4季度准确率 < 55%：失效熔断

## 4. P0 审计层

### 4.1 数据质控官

- 3σ 异常值识别 + 中位数插补（保留趋势信息）
- 缺失值多重插补（短缺口线性，长缺口前向填充）
- 数据质量评分（0-1），低于0.7触发警告

### 4.2 校准风控官

- 三重监控：单次漂移 / 年漂移 / 方向反转次数
- 三种裁决：通过 / 修正步长 / 驳回
- **James-Stein 贝叶斯收缩因子**（shrinkage=0.5）：噪声环境下降低MSE
- 过拟合征兆识别：参数持续调整但准确率下降

### 4.3 因果推断审计 v2.0

三级因果检验：
1. **PSM 倾向得分匹配**（横截面）：控制混淆变量，计算ATE
2. **格兰杰因果检验**（时间序列）：排除反向因果
3. **事件研究法**（事件窗口）：CAR累计异常收益显著性

综合判定：
- 强因果 = 3项全通过
- 弱因果 = 2项通过
- 仅相关 = 1项通过
- 虚假因子 = 0项通过

## 5. P1 增强层

### 5.1 HMM 稳态诊断师

两状态隐马尔可夫模型（稳态/非稳态），Viterbi解码，输出：
- 当前状态 + 置信度
- 状态转移概率矩阵
- 预期持续时间
- 未来20天切换概率

### 5.2 PID 校准优化器

- P（比例）：按误差大小调整
- I（积分）：累积历史偏差，消除稳态误差（含抗积分饱和）
- D（微分）：预测趋势变化，防止超调
- Ziegler-Nichols 自适应整定

### 5.3 赛道生命周期权重

多指标评分（成交额增长/价格趋势/波动率/成交占比），四阶段：
- 萌芽期：权重 0.8
- 成长期：权重 1.2
- 成熟期：权重 1.0
- 衰退期：权重 0.5

### 5.4 EVT 尾部校正 W_T

- POT（超阈值峰值）法拟合 GPD 广义帕累托分布
- Mean Excess Function 自适应选择阈值
- 估计 99% VaR / ES
- 尾部风险超过正态假设时非线性降仓（最低0.6）

## 8. 验证方法论

### 8.1 三层验证体系

1. **单元测试**：每个模块独立功能测试
2. **消融实验**：关闭/开启模块对比，验证边际增益
3. **滚动窗口验证**：逐年滚动模拟，零未来信息，验证实盘有效性

### 8.2 统计显著性

- 所有增益必须通过配对t检验（p<0.10）
- 因果因子必须通过三级因果检验
- 不接受纯相关性作为因子有效的依据

### 8.3 过拟合防控

- 参数年漂移 ≤ 10%
- 校准风控官贝叶斯收缩
- 熔断机制兜底
- 非侵入架构支持一键回退纯核心版
