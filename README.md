# Vκ-RAF∞ 双稳态统一交易理论

> 认知操作系统级量化交易框架 — 复杂系统稳态诊断范式

## 核心理念

Vκ-RAF∞ 不是传统的「预测收益率」模型，而是一套**复杂系统稳态诊断范式**：

- **优先判断**：市场-赛道-个股三层系统是否处于稳态，脆弱性多高
- **然后决策**：基于稳态状态做分层仓位分配与风险约束
- **持续进化**：信号验证闭环 + 滚动校准 + 因果审计，杜绝过拟合与循环论证

## 核心铁律

1. **核心不动原则**：Mκ 公式、已固化参数、基础架构永久冻结，所有优化均为外围增量扩展
2. **非侵入式扩展**：所有扩展模块只读核心输出，不回写核心参数，可开关可回退
3. **无验证不落地**：每个模块必须经过滚动窗口验证 + 因果显著性检验，不达标不纳入
4. **零未来信息**：严格时间隔离，过去校准、未来使用，绝不回溯修正历史
5. **宁少勿滥**：没有明确解决问题、无法验证效果的概念，坚决不引入

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 运行每日哨兵

```bash
# 纯核心版
python scripts/run_daily_sentinel.py

# 启用P0审计层
python scripts/run_daily_sentinel.py --p0

# 启用P1增强层
python scripts/run_daily_sentinel.py --p1

# 使用预设配置
python scripts/run_daily_sentinel.py --preset enhanced

# 启用验证闭环
python scripts/run_daily_sentinel.py --validation
```

### 运行综合测试

```bash
python scripts/test_all.py
```

## 理论基础

- **耗散系统理论**：市场作为远离平衡态的开放系统，稳态与失稳的双稳态切换
- **动理学（Kinetic Theory）**：从微观交易行为到宏观市场状态的统计力学映射
- **胶质稳态理论**：借鉴脑网络中胶质细胞对神经元稳态的维持机制
- **控制论**：PID闭环反馈控制、李雅普诺夫稳定性
- **极值统计**：POT/GPD尾部风险建模
- **因果推断**：PSM倾向得分匹配、格兰杰因果、事件研究法
